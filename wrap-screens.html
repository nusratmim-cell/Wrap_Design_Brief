Shikho Wrap 2026 · Screen Guide · built from the PRD Design Brief

How to read this

What the Wrap is, and the one rule that governs every screen.

What it is

A short, personal, tap-through story — a Shikho খাতা (notebook) — that plays a student their own 2026: how much they studied, how regularly they showed up, how they practised, and finally what kind of learner they are. It ends on a marksheet they can share. 12 screens exist; each student sees a curated 7–8, because the order is server-driven and thin screens drop.

The one rule

We call it a marksheet, but it must never feel like an exam result sheet. Lead with effort and growth, never show a weak number to shame anyone, and give low-activity students a kind Fresh Start instead of empty stats. Every student finishes proud.

Who sees what — the 3 kinds of student

Design every screen for all three. This is the whole “good / honest / low-data” idea in one place — so the screens below only need a single note each.

Full

Lots of activity → the complete story, real badges, a strong learner-type.

Honest

Some activity → only meaningful screens; thin ones quietly dropped. No faked badges.

Fresh Start

Under 5 active days → a short 2-screen deck only. No empty charts, no fake progress.

Golden rule for every screen: if the data isn’t there, the screen is dropped — never shown empty, never “0”, never a filler. That is why each screen below has just one “if data is thin” line.

Rules for every screen

A few things true everywhere, so no single screen has to reinvent them.

What to do when data is missing or looks wrong

These apply to every screen. Read each row left to right: the thing you might run into, then exactly what to do about it.

If this happens
Do this
A metric has no data
Drop that whole screen. Don’t show it empty or padded with filler.
A number comes back as 0 or blank
Print “--”, never a bare “0”.
The student’s name is missing
Use the generic headline. Never print “null” or a blank space.
The name is very long
Wrap it, or trim near ~18 characters. It must never overflow the layout.
No badges were earned
Hide the badge area completely. No empty shelf, no greyed placeholders.
The student re-opens the Wrap
Use the calm entry. Skip the first-time shimmer and reveal animations.
A screen is still loading
Show a notebook-style skeleton, not a spinner.
The student has animations turned off
Everything still works as a clean, static layout — nothing depends on motion.

Look & feel

Shikho × personalised notebook × annual celebration, built on the Homepage Redesign 2026 system so it feels native. One idea per screen, the hero element unmistakable, Bengali numerals throughout. Warm, never childish; celebratory without exaggeration; always accurate to the real number.
