Wrap ২০২৬ — Screen Guide

A calm walk through every screen: what it shows, and how it stays warm for every student. Read it top to bottom.

What it is

  • A tap-through খাতা (notebook) that plays a student their own 2026 — study, classes, practice, and finally their learner-type.
  • 12 screens exist; each student sees a curated 7–8, in a server-driven order.
  • It ends on a marksheet they can share.

The one rule

  • It’s a marksheet, but it must never feel like an exam result sheet.
  • Lead with effort. A quieter student still sees a warm version of each screen — never a “0”, never an empty screen.
  • Only a student with almost no activity (under 5 active days) gets the short, kind Fresh Start deck.

✓

Rules for every screen

A few things true everywhere, so no single screen has to reinvent them.

  1. 1
    Low, even zero → encourage

    Keep the screen, show a warm forward line. Never a bare “0”, never an empty chart, never a fake badge.

  2. 2
    Data genuinely absent → sit out one slide

    Only that slide (rare). We never guess or fake data.

  3. 3
    Under 5 active days → Fresh Start

    The kind 2-slide deck instead of a hollow full one.

  4. 4
    No photo → generic avatar

    A clean male/female avatar, never a blank or wrong face.

  5. 5
    Shared image is identity-safe

    No name, photo, school or rank by default — many students are minors.

  6. 6
    Missing name / long name / missing value

    Generic headline (never “null”), trim ~18 chars, show “--” (never “0”).

  7. 7
    Bangla-first, motion-safe

    Renders in Bangla with Bengali numerals even in an English app; works fully with motion off.

  8. 8
    Everyone finishes proud

    Best, Good or quiet — lead with effort, never shame a number.

Sample names and numbers here (নিশাত · ১৪২ ঘণ্টা…) are illustrative — every real value comes from the student’s own data.
